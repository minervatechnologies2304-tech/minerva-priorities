# Minerva Daily Priorities

Morning meeting tracker for the Minerva Technologies customer service team.

**Open the app:** https://wilkinsonbyron66-hash.github.io/minerva-priorities/

- **Run meeting**: follow up yesterday's priorities person by person, then set today's priorities on an Eisenhower grid, then copy the minutes.
- **Google Sheet backup**: Data & settings › Google Sheet backup. The script is in `google-sheet-backup.gs` (the app also copies it for you with your private key filled in).
- Tasks are kept in the browser and backed up to your own Google Sheet; no task data is stored in this repository.
